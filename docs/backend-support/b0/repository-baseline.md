## Integration and startup

Frontend production API base stays same-origin /api. Existing Vercel rewrite precedes SPA fallback. Vite dev proxy targets local Tomcat. B0 browser smoke serves built dist and proxies only to its owned loopback WAR; no Vercel/Railway requests. It checks the login form and the real unauthenticated API response, while replacing external font/CAPTCHA scripts with inert local responses. It does not claim successful login or CAPTCHA verification.

Embedded Tomcat uses the actual assembled WAR, extracted safely into a disposable directory; required servlet startup failure is fatal.
