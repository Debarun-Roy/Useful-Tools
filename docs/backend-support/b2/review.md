# B2 delivery review

Scope review: schema-only generation, two adapters, deterministic preview/export, integrated editor and external test tooling. No migration/view/evaluator/ETL/auth generator, production SQL execution, new persistence or deployment. All pre-existing B0/B1 uncommitted work is retained; frozen contract byte hashes are asserted by the verifier. B1 browser selectors were narrowed to the labeled historical validation status because B2 adds its own status region; no assertion was removed. Shared external fixture accepts owned B2 directories, and remains excluded from the WAR.

Security review: BoundedJson duplicate/type/depth/body limits execute before contract validation. Unknown fields and raw expressions are rejected. Type-specific defaults are validated before quoted literal emission. Foreign-key names are resolved through stable IDs. Responses contain only constant finding text plus bounded contract paths; no submitted identifiers are reflected in errors. Generate/export independently read strict availability, then decode/validate/assemble; the real shared security filter protects both paths. Early no-store is set in the existing scoped SameSite bypass. No schema, SQL or digest is placed in activity records. ZIP paths are fixed and checked again at packaging; no disk extraction exists in production.

Resource review: rendering and packaging enforce byte/file bounds; preview serialization streams into a bounded buffer. Two slots cover the full request lifetime and reject instead of queuing. Export commits headers after validation/digest/ZIP success. Owned test clusters use loopback only, inherited PG environment is cleared, psql startup files disabled, and stop targets the exact owned data directory. Windows pg_ctl uses DEVNULL handles to avoid descendant pipe inheritance hanging the verifier.

Frontend review using React best-practices checklist: component-local in-memory state, no new global listeners/storage, cleanup invalidates requests, stale identity checks complement aborts, native controls have labels, textareas escape source, callback state changes invalidate generated output, downloads revoke URLs. Invalid/unapplied JSON is explicit and preserved. Sample state does not overwrite personal drafts. Clipboard failures and network failures are announced. Browser assertions cover escaped script text, all themes, two widths, focus, preview/download hashes and late export suppression.

Certification remains evidence-driven: unit/HTTP/database/browser failures must fail the relevant gates. Hosted CI and unsupported runtimes are not represented as executed. See fresh sprint-pass.md/evidence.json for the delivered verdict and exact test counts.

Post-run archive inspection found and corrected the Jan 1 DOS sentinel timezone extra field. A cross-timezone ZIP byte/metadata regression now protects the deterministic archive requirement. The HTTP matrix explicitly exercises successful admin export while disabled. External PostgreSQL prerequisite failures are reported as BLOCKED rather than misreported as executed assertion failures.
