Do not begin B7 automatically. Technical entry requires all G1–G10 PASS in B6 evidence.json with matching final inputs. If any gate fails or is blocked, follow continuation.md before scheduling B7. A technical PASS is not release approval.

Six-module inventory: SQL generation (B1), schema/database migration (B2), deterministic mock data (B3), ETL (B4), authentication core (BS07), and optional user profile (BS08). The latter two are selected within one REST starter and now have Java B5 and Python B6 adapters. Existing contracts/templates remain pinned. Java generator0.5.0 and Python generator0.6.0 share HTTP API0.5.0 and core/profile onoff variants for SQLite/PostgreSQL. See prior sprint handoffs for the first four modules.

Integration: UsefulTools remains the Java generation/export service with canonical manifests, authentication/feature/guest/admin policy, bounded assembly, independent export digest checking and no generated execution. REST editor retains independent target drafts and uses capabilities.python for Python metadata. Python output uses FastAPI/Pydantic/Uvicorn, sqlite3/psycopg, Argon2id, Starsessions RedisStore and HTTPX. Java remains Tomcat/JDBC. Shared executable parity is scripts/b6/application_checks.py plus shared_parity.py using B5 matrix/OpenAPI/browser assertions; exact traces, versions, ZIP digests and commands are in B6 evidence. Do not infer supported runtime versions from compiler targets.

Operational boundaries: Python3.14 single worker/process, root URL only, direct TLS, no forwarded-header trust; loopback-only development cleartext. Redis URL/credentials and database initialization are operator supplied. New empty DB initialization only; no migration of customer auth data. Per-boot Redis namespace deliberately revokes old sessions without global cleanup. Redis TTL bounds idle/absolute life; no in-memory auth fallback. Process-local throttles/session registry and bounded pools do not provide distributed service guarantees. SQLite and PostgreSQL variants have separate data; Java/Python do not share live sessions/password DBs.
